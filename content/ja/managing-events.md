# 予定の作成・編集

予定ダイアログの入力項目と、編集・削除するときの注意点をまとめます。

## 新しい予定を作る

PC では、カレンダー上の作りたい日や時間帯を選ぶと、予定ダイアログが開きます。
スマホでは、カレンダーの「一覧」で日付を選び、「この日に予定を追加」を押します。
入力して「保存」を押すと登録され、「キャンセル」で閉じると何も保存されません。

スマホでは、予定ダイアログが画面全体に広がる編集画面になります（下の
**スマホでの予定の編集**）。入力項目は PC と同じです。

## 入力項目

![予定を追加するダイアログ。タイトル、終日、開始と終了（それぞれ日付の欄と時刻の欄。日付の横に曜日とカレンダーのボタン、時刻の横に時計のボタン）、メモ、カテゴリ、公開範囲、状態、繰り返しの入力欄と、キャンセルと保存のボタンが並んでいる](/content/images/ja/me-dialog-new.png)

上から順に、タイトル、終日の切り替え、開始と終了、メモ、カテゴリ、公開範囲、状態
が並びます。いちばん下の「保存」を押すまで、予定は登録されません。

| 項目 | 必須 | 説明 |
| --- | --- | --- |
| タイトル | 条件つき | 予定の名前です。「状態」が `予定あり (Busy)` のときは必須、`空き時間 (Available)` のときは省略できます |
| 終日 | — | チェックを入れると、時刻を持たない一日単位の予定になります |
| 開始・終了 | 必須 | 時刻を指定する予定の開始と終了です。それぞれ「日付」と「時刻」の2つの欄に分かれています |
| 開始日・終了日 | 必須 | 終日の予定の開始日と終了日です。終了日も予定に含まれます |
| メモ | 任意 | 自分用の覚え書きです。共有リンクの相手には渡りません |
| カテゴリ | 任意 | 予定の色分けに使われます。共有リンクの相手には渡りません |
| 公開範囲 | 必須 | 共有リンクにどこまで開示してよいかを選びます |
| 状態 | 必須 | その時間に連絡がつくかどうかを選びます |

### タイトルが必須になるとき

「状態」が `予定あり (Busy)` の予定は、タイトルを空のままにできません。名前のない予定はたいてい
入力の途中だからです。

「状態」が `空き時間 (Available)` の予定は、タイトルを省略できます。「この2時間は空いています」
という情報だけで意味が通るためです。省略した場合、カレンダー上では「空き時間」と
表示されます。

### 日時と終日の予定

![予定ダイアログの上部。終日にチェックが入っており、開始日と終了日が時刻のない日付だけの欄（2026-10-21 と 2026-10-23）に変わっている](/content/images/ja/me-allday.png)

時刻を指定する予定は「開始」「終了」に日付と時刻を入れます。終了は開始と同じか、
それより後である必要があります。

「終日」にチェックを入れると、入力欄が日付だけの「開始日」「終了日」に変わります。
**終了日も予定に含まれます。** 10月21日から10月23日までの終日予定は、3日間の予定です。

終日の予定が「どの日」なのかは、設定画面のタイムゾーンで決まります。このため、
タイムゾーンを変更すると終日の予定の解釈が変わります。

### 日付と時刻の入力

開始と終了は、それぞれ「日付」の欄と「時刻」の欄に分かれています。終日の予定の
「開始日」「終了日」と、繰り返しの「終了日」も、同じ日付の欄です。

#### PC での入力

キーボードで直接入力するのが基本です。

- **日付**: `20261019`・`2026-10-19`・`2026/10/19` のどれでも入力でき、確定すると
  `2026-10-19` の形になります
- **時刻**: `1430`・`14:30`・`930`・`9:30` のどれでも入力でき、確定すると
  `14:30`・`09:30` の形になります

そのほかの動き:

- 日付を数字だけで入力すると、年の4桁と月の2桁のあとにハイフンが自動で入ります
  （`2026` と打つと `2026-` になります）。ハイフンを自分で入力しても二重には
  なりません。途中の文字の削除や書き換え、貼り付けはそのままできます
- 入力中は、残りの書式（`-MM-DD` や `:mm` など）が薄く表示されます。入力の目安で、
  値には含まれません
- 入力は、Tab で次の欄に移ったとき・Enter を押したとき・欄の外を押したときに確定し、
  上の形に整えられます。確定する前に Esc を押すと、入力前の値に戻ります
- ↑ ↓ キーで、日付は1日ずつ、時刻はカーソルのある側（時または分）が1ずつ変わります
- 時刻は24時間制です。0時は `00:00` です

日付の横のカレンダーのボタン（📅）でカレンダーを、時刻の横の時計のボタン（🕒）で
時計を開けます。どちらも補助で、直接入力と同じ値を選べます。

![予定ダイアログの開始日の下に開いたカレンダー。2026年10月の見出しと前後の矢印、月曜始まりの日付が並び、選んでいる1日が塗りつぶされ、今日の19日に輪郭が付いている。下に今日へとキャンセルのボタンがある](/content/images/ja/me-date-calendar.png)

| カレンダーの操作 | 内容 |
| --- | --- |
| ‹ › | 前後の月に移動します |
| 見出し（2026年10月 など） | 押すと月の一覧、もう一度押すと年の一覧になり、月や年を選べます |
| 今日へ | 今日のある月に移動します。日付は選ばれません |
| 日付を押す | その日に決まり、カレンダーが閉じます |
| キャンセル / Esc | 何も変えずに閉じます |
| キーボード | 矢印キーで日、PageUp / PageDown で月、Shift を押しながらで年を移動し、Enter で選びます |

週は月曜から始まります。カレンダーに日付を消すボタンはありません。

#### スマホでの入力

日付の欄をタップするとカレンダーが、時刻の欄をタップすると時計が、画面の下から
開きます。

![スマホの時刻の選択。09 : 00 の表示の下に24時間のアナログ時計があり、外側に1から12、内側に13から23と00が並ぶ。下に文字で入力・キャンセル・決定のボタンがある](/content/images/ja/me-time-clock.png)

| 操作 | 内容 |
| --- | --- |
| 時を選ぶ | 時計の数字を押すか、なぞります。外側の輪が1〜12時、内側の輪が13〜23時と0時です。指を離すと分の選択に移ります |
| 分を選ぶ | 押すと5分単位、なぞると1分単位で合わせられます。下の −1 / +1 で1分ずつ調整できます |
| 時・分の切り替え | 上の `09` や `00` を押すと、時と分のどちらを選ぶかを切り替えられます |
| 文字で入力 | 時と分を数字で入力します。カレンダーでも「文字で入力」で日付を数字で入力できます |
| 決定 | 選んだ時刻に決まります。カレンダーは日付を押すと決まります |
| キャンセル | 何も変えずに閉じます |

#### 入力できない値

次のような値は、別の値に直されずにエラーになります。欄が赤くなり、理由がその下に
表示されます。直すまで予定は保存できません。

| 入力 | 理由 |
| --- | --- |
| `20260230`（2月30日） | 存在しない日付 |
| `24:00`・`25:00` | 時は0〜23。翌日の0時は、日付を翌日にして `00:00` と入力します |
| `14:78` | 分は00〜59 |
| `9:5` | 09:05 か 09:50 か判別できないため。分は2桁で入力します |

### 夏時間の切り替えにかかる時刻

夏時間（サマータイム）がある地域では、年に2回、時計が進んだり戻ったりします。
日本には夏時間が無いため、日本の時刻で使っている場合、この表示は出ません。

時刻は、お使いの端末（ブラウザ）のタイムゾーンで扱われます。そのタイムゾーンで
切り替えにかかる時刻を開始・終了に入れたときだけ、入力欄の下に案内が出ます。

**存在しない時刻**（例: ニューヨークの2026年3月8日 2:30。2:00 に時計が 3:00 へ進むため、
2:00〜2:59 はありません）

「この時刻は存在しません」と、直前と直後の時刻が表示されます。**このままでは保存
できません。** 時刻を変更してください。別の時刻に自動で直すことはありません。

**2回ある時刻**（例: ニューヨークの2026年11月1日 1:30。2:00 に時計が 1:00 へ戻るため、
1:00〜1:59 が2回あります）

「1回目」「2回目」が、UTC との時差（例: UTC−04:00 / UTC−05:00）つきで表示されます。
どちらかを選んでから保存してください。

選んだ回は、その時刻として保存されます。あとで予定を開き直すと、同じ回が選ばれた
状態で表示されます。時刻を変えずにほかの項目だけを編集しても、予定の時刻は変わりません。

この案内が出るのは、時刻を指定する予定の開始・終了に入力した時刻です。

- 終日の予定は日付だけなので、関係ありません
- 繰り返す予定の2回目以降の各回が切り替えにかかる場合、その回の時刻は繰り返しの
  規則に従って自動で決まります。選ぶ画面は出ません

### メモとカテゴリ

どちらも**自分のためだけの情報**です。共有リンクを渡した相手には届きません。
カテゴリは、カレンダー上で予定を色分けするのに使われます。

### 公開範囲と状態

![公開範囲と状態が別々の入力欄として並んでいるところ。公開範囲は「非公開 (private)」、状態は「予定あり (Busy)」が選ばれている](/content/images/ja/me-visibility-availability.png)

この2つは**別々の設定**で、互いに影響しません。画像のように入力欄も隣り合った
別々のもので、一方を変えても他方は変わりません。

- **公開範囲**は「共有リンクがこの予定をどこまで開示してよいか」
- **状態**は「その時間に連絡がつくかどうか」

6通りすべての組み合わせが有効です。たとえば「公開範囲は `非公開 (private)` だが、
状態は `空き時間 (Available)`」という予定も作れます。これは「空いている時間だが、private を
含めてよい相手にだけ伝えたい」という意味になります。

どの組み合わせが相手に何を見せるのかは
[公開範囲と空き時間](/ja/docs/privacy-and-availability) で詳しく説明します。

## 繰り返す予定

「繰り返し」の欄で、同じ予定を定期的に作れます。

| 項目 | 説明 |
| --- | --- |
| 頻度 | 繰り返さない／毎日／毎週／毎月 から選びます |
| 間隔 | 1〜9999 の整数を入れます。毎週で間隔2なら隔週です |
| 曜日 | 毎週のときに選びます。何も選ばないと開始日の曜日になります |
| 終了 | ずっと続ける／回数を指定する／終了日を指定する から選びます |

![繰り返しの設定欄。頻度は毎週、間隔は2、曜日は水だけが選ばれ、終了は回数で10回に指定されている](/content/images/ja/me-recurrence.png)

上の例は「2週間ごとの水曜日を10回」です。

間隔は 1〜9999、回数は 1〜9,999,999 の整数です。終了日は空のままにできません。範囲外の値は保存されず、理由が表示されます。

### 時刻を指定する繰り返し予定とタイムゾーン

時刻を指定した繰り返し予定は、**決まった時計の時刻**で繰り返します。このため保存には
タイムゾーンの情報が必要です。ブラウザからタイムゾーンを判定できない場合、この種類の
予定は保存できません。その場合はブラウザの日付と時刻の設定を確認してください。

## 予定を編集する

既存の予定を選ぶと、同じダイアログが開きます。スマホでは、予定を押すと画面全体の
編集画面が開きます。

### スマホでの予定の編集

![スマホの予定編集画面。画面全体に広がり、上端にキャンセル・予定を編集・保存、本文に対象、タイトル、終日、開始と終了（日付と時刻をそれぞれタップする欄）、メモ、カテゴリが並び、下端に削除のボタンがある](/content/images/ja/me-mobile-sheet.png)

| 場所 | 内容 |
| --- | --- |
| 上端 | 左に「キャンセル」、右に「保存」 |
| 本文 | PC のダイアログと同じ項目（対象・タイトル・終日・開始と終了・メモ・カテゴリ・公開範囲・状態・繰り返し）。上下にスクロールします |
| 下端 | 「削除」（既存の予定を開いたとき） |

保存できないときは、理由が赤い枠で表示されます。入力した内容は残ります。

### 繰り返す予定を編集するとき

繰り返す予定を開くと、上部に「対象」が表示されます。

![繰り返す予定を開いたときにダイアログの上部に出る対象の選択。この回のみとすべての回の2つがあり、この回のみが選ばれている](/content/images/ja/me-scope.png)

| 選択 | 変更される範囲 |
| --- | --- |
| この回のみ | 選んだ1回だけが変わります。他の回はそのままです |
| すべての回 | 繰り返し全体が変わります |

**「この回のみ」で変更した回がある繰り返し予定は、「すべての回」に変更できません。**
個別に変えた回が失われてしまうためです。その場合は
「個別に変更した回があるため、繰り返し全体の変更はできません」と表示されます。

同じ理由で、個別に変更した回がある繰り返し予定は、繰り返しのタイムゾーンも変更
できません。

## 予定を削除する

ダイアログの「削除」を押します（スマホでは編集画面の下端）。繰り返す予定では、
編集と同じく「対象」の選択が効きます。

| 選択 | 削除される範囲 |
| --- | --- |
| この回のみ | 選んだ1回だけが消えます。他の回は残ります |
| すべての回 | 繰り返し全体が消えます。個別に変更した回もまとめて消えます |

「すべての回」の削除は元に戻せません。

## 気をつけること

- 保存が終わるまで、画面の値はサーバに保存された内容のままです。保存が失敗したときは
  入力した内容が残り、エラーの内容が表示されます
- 予定を削除しても、すでに渡した共有リンクは無効になりません。共有をやめたいときは
  共有リンク側を失効させてください
