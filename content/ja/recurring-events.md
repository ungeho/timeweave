# 繰り返し予定

作り方と編集の操作は [予定の作成・編集](/ja/docs/managing-events) にあります。
この章は、**繰り返し予定が単発の予定と何が違うのか**と、知っておくと困らない制限を
扱います。

## 単発の予定と何が違うのか

単発の予定は1件の予定です。繰り返し予定は**1件の「元になる予定」と、繰り返しの規則**
で表されます。画面に並ぶ何十回ぶんは、その規則から毎回計算されています。

この作りから、次のことが決まります。

| | 単発の予定 | 繰り返し予定 |
| --- | --- | --- |
| 保存されているもの | その予定だけ | 元になる予定＋規則（＋個別に変えた回） |
| 1回だけ変える | その予定を変えるだけ | **「個別に変えた回」が1件増えます** |
| 全体を変える | — | 元になる予定を変えます |
| 回数の上限 | — | 規則から計算されるので、保存件数は増えません |

「ずっと続ける」を選んでも予定が何千件も保存されるわけではありません。表示している
期間のぶんだけが計算されます。

## 指定できる繰り返しの規則

| 項目 | 指定できるもの |
| --- | --- |
| 頻度 | 毎日・毎週・毎月 |
| 間隔 | 1〜9999 の整数 |
| 曜日 | **毎週のときだけ**。複数選べます |
| 終了 | ずっと続ける・回数・終了日 |

曜日を1つも選ばずに「毎週」で保存すると、**開始日の曜日**が使われます。このとき使う
曜日は、カレンダーのタイムゾーンで見た開始日の曜日です。

### 指定できないもの

以下は画面に項目がありません。**できない**という意味です。

| 指定したいこと | 現状 |
| --- | --- |
| 毎年 | 選べません |
| 「毎月第2月曜」のような序数つきの曜日 | 選べません |
| 「毎月15日と末日」のような日付指定 | 選べません |
| 「毎月」で曜日を指定する | 毎週のときだけ有効です |
| 回数と終了日を両方指定する | どちらか一方です |

他のカレンダーから持ち込んだ規則がこの範囲を超えている場合、TimeWeave はその規則を
推測で解釈しません。そのような繰り返し予定はカレンダーに表示せず、画面の上に
「表示できない繰り返し予定があります」と件数を表示します。ほかの予定はそのまま
表示されます。

## 「毎月」の日付の決まり方

毎月の繰り返しは、**元になる予定と同じ日**に繰り返します。間隔が2なら2か月ごとです。

その日が存在しない月は**飛ばされます**。31日に作った毎月の予定は、2月・4月・6月・
9月・11月には現れません。30日に繰り下がることはありません。

月末ごとに繰り返したい場合、現状では該当する日付ごとに別の予定を作る必要があります。

## 終了の指定

| 選択 | 意味 |
| --- | --- |
| ずっと続ける | 終了しません |
| 回数 | その回数ちょうどで終わります（1〜9,999,999） |
| 終了日 | その日まで繰り返します。**終了日を含みます** |

終了日の扱いは、終日の予定と時刻を指定した予定で違います。

- **終日の予定**: 暦の日付として扱われます。タイムゾーンによる変換は起きません。
- **時刻を指定した予定**: その日の終わりまで（カレンダーのタイムゾーンで 23:59:59.999）
  として扱われます。

## 個別に変えた回

繰り返しのうち1回だけを「この回のみ」で変更すると、その回は**その時点の内容の写し**
として別に保存されます。1回だけ削除した場合も、「この回は無い」という記録が残ります。

ここから次の2つが決まります。どちらも操作が拒否される形で現れます。

| 起きること | 表示される内容 |
| --- | --- |
| 個別に変えた回があると「すべての回」に変更できない | 個別に変更した回があるため、繰り返し全体の変更はできません |
| 同じ理由で、繰り返しのタイムゾーンも変更できない | 個別に変更した回があるため、繰り返しのタイムゾーンは変更できません |

**写しは規則から計算されたものではないため、規則を変えると意味を失います。**
TimeWeave は写しを黙って捨てるよりも、操作を拒否する側を選んでいます。

個別に変えた回を整理してからであれば、全体を変更できます。個別変更の件数にも上限が
あり、超えると「この繰り返し予定の個別変更が上限に達しました」と表示されます。

## タイムゾーンは規則の一部です

時刻を指定した繰り返し予定は、**決まった時計の時刻**で繰り返します。「毎朝9時」は、
どのタイムゾーンの9時なのかが決まっていなければ意味が定まりません。

このため、時刻を指定した繰り返し予定の保存にはタイムゾーンが必要です。ブラウザから
判定できない場合、この種類の予定は保存できません。

繰り返しのタイムゾーンを変えると、**すべての回が別の瞬間に移動します**。予定の名前を
変えただけでタイムゾーンが書き換わることはありません。タイムゾーンの変更は別の操作
として用意されています。

詳しくは [タイムゾーン](/ja/docs/time-zones) をご覧ください。

## 夏時間の切り替え日の回

時刻を指定した繰り返し予定の回は、繰り返しのタイムゾーンで毎回同じ時計の時刻に
置かれます。そのタイムゾーンに夏時間がある場合、切り替えの日だけは次のように
なります。1回だけの予定を入力するとき（[タイムゾーン](/ja/docs/time-zones) の
「夏時間の切り替えと時刻の入力」）とは違い、**繰り返しの回は自動で決まり、確認は
求められません。**

| その日の時刻 | 回の置かれ方 | 例: America/New_York の毎週日曜 |
| --- | --- | --- |
| 存在しない時刻（時計が進む間） | 時計が進んだ分だけ後ろの時刻に置かれます。回が消えることはありません | 2:30 の予定は、2026年3月8日だけ 3:30 になります |
| 2回ある時刻（時計が戻る間） | **2回目**の時刻に置かれます。1回目には置かれません | 1:30 の予定は、2026年11月1日は時計が戻った後の 1:30 になります |

時計が深夜0時をまたいで進む地域では、回が**翌日**に移ることがあります。
グリーンランドの America/Nuuk では 2026年3月28日（土）の 23:00〜23:59 が存在しない
ため、毎週土曜 23:30 の予定は、その週だけ**3月29日（日）の 0:30** になります。

共有ページの「予定あり」も同じ時刻になります。その回だけ別の時刻にしたいときは、
「この回のみ」を選んで編集してください。

タイムゾーンが「未設定」の古い繰り返し予定は、この規則ではなく端末の時計で回が
決まり（2回ある時刻は1回目）、共有ページではその期間の空き時間を判定できません。
予定を開いて「タイムゾーン」の「現在のタイムゾーン（…）を設定」を押すと、上の規則で
扱われます。個別に変えた回がある繰り返しでは設定できません。

## 共有への影響

ここが見落としやすいところです。

**「毎月」の繰り返し予定が共有している期間に関わると、相手の画面では空き時間が
「判定できませんでした」になります。**

共有画面の空き時間は、サーバ側で繰り返しを正確に展開できたときだけ計算されます。
毎日・毎週は展開できますが、**毎月は現在のサーバ側では展開できません**。正確に
数えられない期間について推測で答えるより、判定できないと伝える設計になっています。

次の場合も同じ結果になります。

| 原因 | 結果 |
| --- | --- |
| 「毎月」の繰り返しが期間に関わる | 空き時間は判定できません |
| 時刻を指定した繰り返しのタイムゾーンが決まっていない | 同じ |
| その期間の繰り返し回数が多すぎる（展開の上限を超える） | 同じ |
| サーバが扱えない規則が保存されている | 同じ |

この「判定できませんでした」は、**空いていないという意味ではありません**。
[共有相手に見える画面](/ja/docs/what-viewers-see) で詳しく説明します。
