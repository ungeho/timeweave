# 共有相手に見える画面

共有リンクを開いた相手には、専用の読み取り専用の画面が表示されます。この章は
**その画面に何が出て、何が出ないのか**を扱います。

相手はログインしません。アカウントも必要ありません。

## 出ないもの

| 相手に渡らないもの |
| --- |
| 予定の名前 |
| メモ |
| カテゴリ |
| 公開範囲（private / busy_only / public のどれであるか） |
| 予定の件数 |
| あなたのメールアドレスや名前 |

**公開範囲を「公開(public)」にしても、予定の内容は相手に渡りません。**
公開範囲は「この予定の時間帯を共有に含めてよいか」を決める設定で、内容を見せる
設定ではありません。

相手に渡るのは**時間帯だけ**です。

## 出るもの

画面には週の枠があり、曜日ごとに時間帯が並びます。「今週」「前の週」「次の週」で
期間を移動できます。

| 表示 | 意味 |
| --- | --- |
| 予定あり | その時間に予定があります |
| 終日 予定あり | その日は終日の予定があります |
| 空き時間 | 共有者が**空き時間として登録した**時間です |
| 終日 空き時間 | その日は終日で空き時間として登録されています |

「予定あり」と「空き時間」は、塗りと斜線で見た目が分かれています。色だけに
頼っていないため、白黒でも区別できます。それぞれの帯には「予定あり」「空き時間」の
文字と時刻も入ります。

週の上には「表示の見かた」が常に表示され、どちらの帯が何を意味するかと、
**何も表示されていない時間が空いているとは限らない**ことを説明します。空き時間を
公開していないリンクでは、「予定あり」の説明だけが出ます。何も表示されていない日には
「—」が入ります。

画面の下部には、何が共有されているかの説明が常に表示されます。空き時間が画面に
出ているときは、より詳しい文に変わります。

## 「空き時間」の意味を間違えないでください

**空き時間として表示されていない時間が、空いているとは限りません。**

空き時間の帯は、共有者が予定を明示的に「空き時間」として登録し、かつ共有リンクで
その公開を許可したときだけ出ます。予定の入っていない時間が自動的に空き時間として
表示されることはありません。

画面下部の説明にも、同じことが書かれています。

## 空き時間の3つの状態

空き時間については、**3つの答えのうち1つ**が返ります。相手の画面はそれぞれ別の
表示になります。

| 状態 | 画面に出るもの | 意味 |
| --- | --- | --- |
| 判定できた（空き時間あり） | 空き時間の帯 | その期間の空き時間を正確に計算できました |
| 判定できた（空き時間なし） | この期間に共有されている空き時間はありません | 正確に計算した結果、公開対象の空き時間がありませんでした |
| **判定できなかった** | 空き時間を正確に判定できませんでした | 計算できませんでした |

空き時間を公開していないリンクでは、空き時間についての表示そのものが出ません。
この場合も「空き時間がない」という意味ではありません。

### 「判定できませんでした」は「空いていない」ではありません

これはいちばん誤解されやすい表示です。

**これは知識の不足を伝えるものであり、空き時間の不在を伝えるものではありません。**

![共有リンクを開いた相手の画面。空き時間を正確に判定できなかったことを伝える警告が上部にあり、その下に予定ありの帯だけが並んでいる。空き時間の帯は一つもない](/content/images/ja/pa-viewer-indeterminate.png)

画面には「この期間については、空いているかどうかを確認するには直接ご連絡ください」
と続きます。確認が必要であることを伝える表示です。

この画面では**空き時間の帯が1つも出ません**。予定ありの帯は出ていますが、
その隙間が空いているという意味にはなりません。

### 「ありません」との違い

| 表示 | 計算 | 意味 |
| --- | --- | --- |
| この期間に共有されている空き時間はありません | **できた** | 公開対象の空き時間が無いと確かめられました |
| 空き時間を正確に判定できませんでした | **できなかった** | 分かりません |

![共有リンクを開いた相手の画面。この期間に共有されている空き時間はありませんという案内が上部にあり、その下に予定ありの帯が並んでいる](/content/images/ja/pa-viewer-empty.png)

見た目はよく似ていますが、**上の帯の文が違います**。こちらは計算できたことを
伝えており、警告ではなく案内として表示されます。

「ありません」も、**共有されている**空き時間が無いという意味です。共有者が暇でない
という意味ではありません。

### 判定できなくなるのはどんなときか

| 原因 |
| --- |
| 「毎月」の繰り返し予定がその期間に関わっている |
| 時刻を指定した繰り返し予定のタイムゾーンが決まっていない |
| 終日の予定と時刻指定の予定が同じ期間にあり、共有者のタイムゾーンが未設定 |
| その期間の繰り返し回数が多すぎる |
| サーバが扱えない繰り返しの規則が保存されている |

共有者の側でできる確認は [よくある質問](/ja/docs/faq) にあります。

## 予定ありが優先されます

同じ時間に「予定あり」と「空き時間」が重なった場合、**予定ありが優先されます。**
その時間は空き時間としては表示されません。

誤って「空いている」と伝わるより、「予定がある」と伝わるほうが安全だからです。

![共有リンクを開いた相手の画面の一日分。15時から16時が塗りつぶしの予定ありの帯、14時から15時と16時から17時が斜線の空き時間の帯として、別々の見た目で並んでいる](/content/images/ja/pa-busy-wins.png)

上の画面は、共有者が14時から17時を空き時間として登録し、その途中の15時から16時に
予定が入っている場合です。重なった1時間は**空き時間から取り除かれ**、残りの
14時から15時と16時から17時だけが空き時間として出ています。

**帯は時刻順には並びません。** 予定ありの帯がまとめて先に、空き時間の帯が
そのあとに並びます。時刻は各帯に書かれているので、そちらで読んでください。

## 未対応の繰り返しが含まれる期間

その期間に正確に展開できない繰り返し予定が含まれる場合、画面に次の注意が出ます。

> この期間には未対応の繰り返し予定が含まれています。表示されていない時間も空いて
> いるとは限りません。

この注意が出ている期間は、**表示されている「予定あり」が全部とは限りません。**

## リンクが使えないとき

リンクが使えない場合、相手の画面には1つの文が出ます。

> この共有リンクは利用できません。

![共有リンクを開いた相手の画面。この共有リンクは利用できませんという一文だけが表示され、週の切り替えも予定の枠も出ていない](/content/images/ja/wvs-unavailable.png)

**理由は相手に伝わりません。** 期限切れ・失効・削除・存在しないURL・壊れたURLは、
すべて同じ表示になります。どのリンクがどの状態かを外部から調べられないように
するためです。

週の切り替えも予定の枠も出ません。**期間を変えて調べ直すこともできません。**

## 予定が1件も共有されていないとき

> この期間に共有されている予定はありません。

これは**その期間に共有対象の予定が無い**という意味です。共有者の予定が無いという
意味ではありません。公開範囲の設定によって共有対象から外れている可能性があります。

## 取得に失敗したとき

> 空き時間を取得できませんでした。時間をおいて再読み込みしてください。
> （この画面は「予定なし」を意味しません）

後ろの一文は、エラー画面が「予定なし」と読まれないために付いています。

短時間にアクセスが集中した場合も、一時的に取得できなくなることがあります。

## 相手の画面の言語

相手の画面は、**相手のブラウザの言語**で表示されます。共有者の言語設定は使われ
ません。共有ページでは共有者の設定を取得すらしていません。

詳しくは [言語設定](/ja/docs/language) をご覧ください。
