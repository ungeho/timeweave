# よくある質問

## 共有について

### 予定が共有相手に見えません

公開範囲を確認してください。

| 公開範囲 | 共有リンクに出るか |
| --- | --- |
| 非公開 (private) | リンクで「非公開(private)の予定も busy として含める」をオンにしたときだけ出ます |
| 予定ありのみ (busy_only) | 出ます |
| 公開 (public) | 出ます |

非公開のままで出したい場合は、**リンク側**の「非公開(private)の予定も busy として
含める」をオンにします。予定を作り直す必要はありませんが、**この設定は後から
変更できません**。新しいリンクを作ってください。

期間も確認してください。相手は週単位で表示しています。予定がその週にあるか
確認してください。

### 共有相手に予定の名前が見えてしまいますか

いいえ。予定の名前・メモ・カテゴリは、**どの設定でも相手に渡りません。**

公開範囲を「公開(public)」にしても内容は渡りません。公開範囲は時間帯を共有に
含めるかどうかを決める設定です。

### 空き時間(Available)が表示されません

上から順に確認してください。

| 確認 | 内容 |
| --- | --- |
| 1 | 予定の「状態」を**空き時間 (Available)** にしましたか |
| 2 | 共有リンクの「空き時間も公開する」をオンにしましたか |
| 3 | その予定が**非公開**なら、「非公開も含める」も**同時に**オンですか |
| 4 | 同じ時間に「予定あり」の予定が重なっていませんか |
| 5 | その期間に「毎月」の繰り返し予定が関わっていませんか |

2は有効なリンクなら後から切り替えられます。3は作り直しが必要です。

4の場合、**予定ありが優先されます**。重なった時間は空き時間として表示されません。

### 予定を入れていない時間は空き時間になりませんか

なりません。空き時間として表示されるのは、予定を**明示的に「空き時間」として登録
した時間だけ**です。

予定の入っていない時間が自動的に空き時間として公開されることはありません。

### 「空き時間を正確に判定できませんでした」と出ます

これは**空き時間が無いという意味ではありません。** 計算できなかったという意味です。

共有者の側で確認できることは次のとおりです。

| 確認 | 対処 |
| --- | --- |
| その期間に「毎月」の繰り返し予定があるか | 現状、毎月の繰り返しはサーバ側で展開できません |
| 時刻を指定した繰り返し予定のタイムゾーンが決まっているか | 設定してください |
| 終日の予定と時刻指定の予定が同じ期間にあり、カレンダーのタイムゾーンが未設定か | 設定してください |
| その期間の繰り返し回数が非常に多くないか | 期間を分けるか、繰り返しを整理してください |

### 「この期間に共有されている空き時間はありません」と出ます

こちらは計算が**できた**うえでの結果です。公開対象の空き時間が無いと確かめられて
います。

「判定できませんでした」との違いは [共有相手に見える画面](/ja/docs/what-viewers-see)
にあります。

### 共有リンクが使えないと言われます

相手には理由が出ません。共有者の側で「既存のリンク」の状態を確認してください。

| 状態 | 対処 |
| --- | --- |
| 期限切れ | 新しいリンクを作ってください |
| 失効済 | 新しいリンクを作ってください |
| 有効 | URLが正しく渡っているか確認してください |

### 共有リンクのURLが分からなくなりました

**再表示はできません。** URLは作成時にしか表示されず、トークンは保存されていません。

そのリンクを失効させて、作り直してください。

### 予定を削除したら共有リンクも無効になりますか

なりません。共有をやめたいときは**リンクを失効させてください。**

### 共有リンクが作れません

| 表示 | 対処 |
| --- | --- |
| 有効な共有リンクの数が上限に達しました | 不要なリンクを失効させてください（上限25） |
| 共有リンクの総数が上限に達しました | **失効済みのリンクを削除**してください（上限200） |
| 作成が短時間に集中した | 表示される時間だけ待ってください |

**失効させるだけでは総数は減りません。** 総数の枠を空けるには削除が必要です。

## 日時について

### 共有相手と時刻が合いません

相手の画面は**相手のブラウザのタイムゾーン**で表示されます。同じ瞬間を相手の時刻で
表しているため、表示が違うのは正常です。

### 終日の予定が1日ずれて見えます

終日の予定は**設定したカレンダーのタイムゾーン**の暦日として扱われます。ブラウザの
タイムゾーンと設定が違う場合、ずれて見えます。

設定を確認してください。詳しくは [タイムゾーン](/ja/docs/time-zones) にあります。

### タイムゾーンを変えると予定が動きますか

**時刻を指定した予定は動きません。** 変わるのは終日の予定がどの暦日になるかと、
匿名共有ページの空き時間の表示です。

### 日付や時刻を入れると欄が赤くなります

入力した値を日付・時刻として読めないときです。欄の下に理由が出ます。

- **日付**: `20261019`・`2026-10-19`・`2026/10/19`
- **時刻**: `1430`・`14:30`・`930`・`9:30`（24時間制）

存在しない日付（2月30日など）や `24:00`・`14:78` のような時刻は、別の値に直されずに
エラーになります。赤い欄が残っている間は保存できません。確定前なら Esc で入力前の値に
戻せます。

### 「この時刻は存在しません」と出ます

夏時間に切り替わる日に、時計が進んで飛ばされる時刻を入れたときです。この時刻は
保存できないので、時刻を変更してください。自動で別の時刻に直すことはありません。
詳しくは [予定の作成・編集](/ja/docs/managing-events) にあります。

### 「1回目」「2回目」を選ぶよう求められます

夏時間が終わる日に、時計が戻って2回ある時刻を入れたときです。UTC との時差を見て、
どちらかを選んでから保存してください。選んだ回は保存され、予定を開き直しても
同じ回のままです。

### 「このタイムゾーンは使用できません」と出ます

ブラウザが報告したタイムゾーン名をサーバが扱えません。ブラウザの日付と時刻の設定を
確認してください。

### 時刻を指定した繰り返し予定が保存できません

「繰り返し予定のタイムゾーンを決定できなかったため、保存できませんでした」と
表示されている場合、ブラウザからタイムゾーンを判定できていません。ブラウザの
日付と時刻の設定を確認してください。

## スマホについて

### 設定やログアウトが見つかりません

画面の幅が狭いとき（720px 未満）は、「設定」「使い方ガイド」「ログアウト」は
画面右上のメニュー（☰）の中にあります。テーマの切り替えはメニューの外に残ります。

### 月・週・日の表示がありません

スマホでは「一覧」と「月」の2つの表示になります。詳しくは
[はじめに](/ja/docs/getting-started) にあります。

## 言語について

### 共有相手の画面が英語になります

相手のブラウザが英語だからです。**共有者の言語設定は相手の画面に影響しません。**

### 言語を変えると共有内容が変わりますか

変わりません。変わるのは画面の文字だけです。

### 言語の設定が保存できません

保存に失敗した場合、**表示言語は変わりません。** 選択した内容は入力欄に残るので、
もう一度「保存」を押してください。

### ガイドが英語になりません

ガイドの言語は**URLで決まります**。`/en/docs/...` を開いてください。ガイドの
各ページにある言語の切り替えからも移動できます。

まだ翻訳されていない章では、英語のURLでも日本語の本文が表示され、その旨の通知が
出ます。

## 繰り返し予定について

### 「毎年」が選べません

現在は毎日・毎週・毎月だけです。

### 「毎月第2月曜」のような指定ができません

序数つきの曜日指定はできません。曜日を選べるのは「毎週」のときだけです。

### 31日の毎月の予定が、ない月に出ません

その日が存在しない月は**飛ばされます**。30日に繰り下がることはありません。

### 「すべての回」に変更できません

「個別に変更した回があるため、繰り返し全体の変更はできません」と表示されている
場合、その繰り返しには「この回のみ」で変えた回があります。

個別に変えた回は**その時点の内容の写し**として保存されており、規則を変えると意味を
失います。個別変更を整理してから、全体を変更してください。

### 繰り返しのタイムゾーンが変更できません

同じ理由です。個別に変更した回がある繰り返し予定では、タイムゾーンも変更できません。

### 繰り返し予定の個別変更が上限に達しました

1つの繰り返し予定に作れる個別変更の数には上限があります。不要な個別変更を整理して
ください。

## 保存について

### 予定が保存できません

| 表示 | 対処 |
| --- | --- |
| タイトルを入力してください | タイトルが必要な条件を満たしていません |
| 保存できる予定の上限に達しました | 不要な予定を削除してください |
| 保存が短時間に集中したため | 表示される時間だけ待ってください |
| 文字数の上限 | 該当の欄を短くしてください |

### 保存に失敗したとき、入力した内容は消えますか

消えません。入力した内容は残り、エラーの内容が表示されます。画面の値は**サーバに
保存された内容のまま**です。
