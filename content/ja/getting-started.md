# はじめに

TimeWeave は、自分の予定を管理しながら、**空いている時間だけを相手に伝える**ための
カレンダーです。予定表そのものを見せることなく、「この時間は埋まっている」「この時間なら
連絡がつく」とだけ共有できます。

## TimeWeave でできること

| できること | 説明 |
| --- | --- |
| 予定を管理する | 日時を決めた予定、終日の予定、繰り返す予定を登録できます |
| 予定を見せずに共有する | 共有リンクを作ると、相手はタイトルや内容を見ずに、空き具合だけを確認できます |
| 連絡がつく時間を示す | 予定を「連絡がつく時間」として登録しておくと、相手にその時間だけを伝えられます |

共有リンクを受け取った相手は、ログインせずに閲覧できます。そのかわり、相手に見えるのは
**時間帯だけ**です。予定のタイトル・メモ・カテゴリが相手に渡ることはありません。

## 最初に確認する設定

「設定」を開いて、次の2つを確認してください。PC では画面右上に、スマホでは
画面右上のメニュー（☰）の中にあります。

![設定ダイアログ。タイムゾーンの入力欄に Asia/Tokyo が入っており、その下に終日の予定の扱いを説明する文、表示言語の選択、言語設定は空き時間の計算に影響しないという注意、保存と閉じるのボタンが並んでいる](/content/images/ja/gs-settings.png)

設定画面のいちばん上には、ログイン中のアカウント（メールアドレス）が表示されます。

### タイムゾーン

**終日の予定がどの日に属するかを決める設定**です。ここが未設定のままだと、終日の予定と
時刻を指定した「連絡がつく時間」が同じ期間に入っているとき、共有リンクで空き時間を
表示できません。安全のために非表示になります。

住んでいる地域のタイムゾーンを選んでおいてください。設定画面にも同じ説明があります。

タイムゾーンを変えると、終日の予定の解釈が変わります。詳しくは
[公開範囲と空き時間](/ja/docs/privacy-and-availability) で説明します。

### 表示言語

画面の文言を日本語と英語から選べます。「ブラウザの設定に従う」を選ぶと、お使いの
ブラウザの言語設定に合わせて切り替わります。

この設定は画面の見た目を変えるだけで、**共有される空き時間の計算には影響しません**。

## カレンダーの3つの表示

PC（画面の幅が 720px 以上）では、画面上部のボタンで切り替えます。スマホの表示は
次の**スマホでのカレンダー**で説明します。

| 表示 | 向いている用途 |
| --- | --- |
| 月 | 1か月の予定の入り具合を俯瞰する |
| 週 | 時間帯ごとの予定を確認する。週の始まりは月曜日です |
| 日 | 1日の予定を時間単位で詳しく見る |

「今日」を押すと今日を含む期間に戻ります。左右の矢印で前後に移動できます。

![月表示のカレンダー。上部に今日・前後の矢印・月週日の切り替え・共有のボタンがあり、週は月曜から始まる。各日の枠に予定が並び、終日の予定は複数日にまたがる1本の帯として出ている](/content/images/ja/gs-month-view.png)

月表示では、週は**月曜から**始まります。終日の予定は、またがる日数ぶんの1本の帯
として出ます。

![週表示。上端に終日の予定のレーンがあり、その下に24時間表記の時刻目盛が縦に並ぶ。時刻を指定した予定が曜日の列に置かれ、空き時間として登録した予定だけ斜線で描かれている](/content/images/ja/gs-week-view.png)

週表示では、終日の予定が上端のレーンにまとまり、時刻を指定した予定は24時間の
目盛の上に置かれます。**斜線の予定は「空き時間」として登録したもの**です。

## スマホでのカレンダー

スマホなど画面の幅が狭いとき（720px 未満）は、カレンダーが「一覧」と「月」の
2つの表示になります。最初は「一覧」です。

![スマホのカレンダー画面の上部。TimeWeave の横にテーマ切替とメニューのボタン、その下に共有、前後の矢印つきの日付、今日・一覧・月の切り替え、月曜から日曜までの7日分の日付が並び、選んだ日の予定と「この日に予定を追加」のボタンが出ている](/content/images/ja/gs-mobile-agenda.png)

| 部分 | 使い方 |
| --- | --- |
| 7日分の日付 | 月曜から日曜までの1週間です。日付を押すと、その日の予定が下に並びます。予定のある日には小さな点が付きます |
| ‹ › | 「一覧」では1週間ずつ、「月」では1か月ずつ前後に移動します |
| 今日 | 今日に戻ります |
| 一覧 | 選んだ日の予定を、時刻のある予定と終日の予定に分けて並べます |
| この日に予定を追加 | 選んでいる日に新しい予定を作ります |

![スマホの月表示。月曜始まりの1か月分の日付が並び、予定のある日には小さな点が付いている。選んでいる19日が強調されている](/content/images/ja/gs-mobile-month.png)

「月」を押すと、1か月分の日付が表示されます。予定のある日に点が付くだけの
コンパクトな表示で、日付を押すとその日の「一覧」に切り替わります。

PC の月・週・日の表示は、スマホでは使いません。

## スマホでの画面の違い

画面の幅が 720px 未満のときは、次の部分が PC と違います。機能そのものは同じで、
PC でできることはスマホでもできます。

![スマホのヘッダー。メニューのボタンを押すと、設定・使い方ガイド・ログアウトの3つが並んだメニューが開く。テーマ切替のボタンはヘッダーに残っている](/content/images/ja/gs-mobile-menu.png)

| 部分 | PC | スマホ |
| --- | --- | --- |
| 設定・使い方ガイド・ログアウト | 画面右上に並びます | 右上のメニュー（☰）の中にあります |
| テーマの切り替え | 画面右上 | 画面右上（メニューの外） |
| 予定の作成・編集 | 画面の中央に開くダイアログ | 画面全体に広がる編集画面 |
| 共有 | カレンダー上部の「共有」から開くダイアログ | ヘッダーの下の「共有」から開く、画面全体の画面 |
| 日付・時刻の入力 | 直接入力。カレンダーと時計は補助 | 欄をタップしてカレンダー・時計から選ぶ |

ログインしていないときはメニューが無く、「使い方ガイド」へのリンクが直接表示されます。

このガイドは、アプリの「使い方ガイド」（スマホではメニューの中）から開けます。
ガイドの各ページの上部にある「カレンダーへ戻る」でアプリに戻れます。

## 予定を作るまでの流れ

1. PC ではカレンダーの空いているところを選び、スマホでは「一覧」の
   「この日に予定を追加」を押して、予定ダイアログを開きます
2. 「タイトル」を入力します
3. 日時を決めます。日付と時刻は直接入力するか、カレンダーと時計から選べます。
   一日中の予定なら「終日」にチェックを入れます
4. 「公開範囲」で、共有リンクにどこまで見せてよいかを選びます
5. 「状態」で、その時間に連絡がつくかどうかを選びます
6. 「保存」を押します

各項目の詳しい説明は [予定の作成・編集](/ja/docs/managing-events) にあります。
