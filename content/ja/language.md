# 言語設定

TimeWeave は日本語と英語で表示できます。

## 設定する

設定の「表示言語」で選びます。

| 選択 | 動作 |
| --- | --- |
| ブラウザの設定に従う | ブラウザの言語から決めます（初期状態） |
| 日本語 | 日本語で表示します |
| English | 英語で表示します |

「保存」を押すと保存されます。選んだ言語は、次にログインしたときにも使われます。

## 表示言語の決まり方

上から順に判定され、**最初に当てはまったものが使われます**。

| 順 | 条件 |
| --- | --- |
| 1 | 保存された選択がある（日本語 / English） |
| 2 | ブラウザの言語に、対応している言語がある |
| 3 | どちらでもない → 日本語 |

### ブラウザの言語の見方

ブラウザが報告する言語の一覧を、**上から順に**調べます。最初に見つかった対応言語が
使われます。

第1希望がフランス語、第2希望が英語の場合、**英語**になります。対応していない言語で
止まることはありません。

地域は無視されます。`en-US`・`en-GB`・`EN` はすべて英語として扱われます。

## ログインしていないときの画面

ログイン画面と共有ページには、保存された設定がありません。この場合は
**ブラウザの言語**が使われます（上の表の2番目）。

## 共有相手の画面の言語

**共有リンクを開いた相手には、相手のブラウザの言語で表示されます。**

共有者の言語設定は使われません。共有ページでは共有者の設定を**取得すらしていません**。

| | どの言語になるか |
| --- | --- |
| 自分の画面 | 保存した設定（なければ自分のブラウザ） |
| 共有相手の画面 | **相手のブラウザ** |

日本語で設定していても、英語のブラウザの相手には英語で表示されます。相手が読めない
言語の画面を渡さないための動作です。

### タイムゾーンとは逆向きです

| | 誰のものか |
| --- | --- |
| 言語 | **見ている人**のもの |
| タイムゾーン | **共有者**のもの |

言語は読む人に合わせるべきもの、タイムゾーンは予定の意味を決めるものだからです。
詳しくは [タイムゾーン](/ja/docs/time-zones) をご覧ください。

## 言語は共有の内容を変えません

設定画面にも書かれています。

> 言語設定は、共有される空き時間の計算には影響しません。

言語を変えても、相手に見える時間帯は変わりません。変わるのは画面の文字だけです。

## ログイン直後に一瞬ブラウザの言語になる

ログインした直後、保存された設定を読み込むまでのわずかな間、ブラウザの言語で
表示されることがあります。読み込みが終わると保存した言語に切り替わります。

設定が読み込めていない状態で保存された言語を使うと、別のアカウントの設定が残って
表示される可能性があるため、読み込めるまでは使わない作りになっています。

## 保存に失敗したとき

保存が失敗した場合、**表示言語は変わりません。**

| 状態 | 内容 |
| --- | --- |
| 画面の言語 | 保存されている言語のまま |
| 選択した内容 | 入力欄に残ります |
| エラー | 原因が表示されます |

保存されなかった変更で画面の言語が変わってしまうと、「保存できたのかどうか」が
分からなくなります。画面の言語は**保存に成功した値だけ**に従います。

もう一度「保存」を押すと再試行できます。

## ガイドの言語

この使い方ガイドは日本語と英語で読めます。**ガイドの言語は画面の言語とは別に、
URL で決まります。** `/ja/docs/...` なら日本語、`/en/docs/...` なら英語です。
共有されたガイドのリンクが、送った人と同じ内容で読めるようにするためです。

まだ翻訳されていない章を英語で開いた場合は、日本語の本文が表示され、その旨の
通知が出ます。訳の無い章を空白にするより、読める言語で出すほうが役に立つ
ためです。
